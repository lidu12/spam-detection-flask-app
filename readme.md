# 📩 Spam Detection Web App (Flask + Machine Learning)

A full-stack machine learning web application that detects whether an SMS message is **Spam or Not Spam**, built using Flask and deployed on Render.

---

## 🌐 Live Demo
👉 https://spam-detection-app-u4sw.onrender.com/

---

## 🧠 Project Overview
This project uses a **Naive Bayes machine learning model** trained on SMS data to classify messages as spam or not spam.  
It includes a full web interface and user authentication system.

---

## ⚙️ Features
- 📩 Spam vs Not Spam classification
- 📊 Confidence score prediction
- 🔐 User login & registration system
- 🌐 Web interface using Flask
- ☁️ Deployed on Render
- 🎨 Clean and modern UI

---

## 🛠️ Tech Stack
- Python
- Flask
- Scikit-learn
- Pandas
- HTML / CSS
- Machine Learning (Naive Bayes)
- Render (Cloud Deployment)

---


---

## 🧠 How It Works
1. User enters a message
2. Text is cleaned and processed
3. Machine learning model analyzes it
4. Prediction (Spam / Not Spam)
5. Confidence score is displayed
